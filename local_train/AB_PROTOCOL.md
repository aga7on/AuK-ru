# AB_PROTOCOL — пилот A/B (зафиксировано 16.09.2026)

Сравнение двух режимов дообучения от u10000 с целью выяснить цену сохранения инструментов.

## Условия

| Параметр | A | B |
|---|---|---|
| Инициализация | `merged\auk_ru_10000.safetensors` | тот же файл |
| Русские данные | `data_s2_full` (10,003 no-ref + 7,503 пар) | тот же набор |
| Инструментальные данные | — | `data_s2_tools_v3` (21,407, синтетика помечена) |
| Доля примеров | 100% речь | **80% речь / 20% tools** |
| LoRA / обучаемые параметры | r32/α64, peft + fusion | идентично A |
| LR | `2e-5` | `2e-5` |
| Optimizer/scheduler | новые (не resume) | новые |
| Seed (train) | 7 | 7 |
| Warmup | 25 | 25 |
| Стоп | clean stop на u500 (`--max_updates`, аддитивный патч train.py 16.09) | идентично A |
| Dev, сид генерации инференса | общие | общие |
| Папки | `run_s2_A` | `run_s2_B` |
| Бюджет | 500 обновлений | 500 обновлений |

80/20 — стартовая гипотеза; не «объединять файлы целиком» (иначе tools >50% записей).

## Логирование (обязательное)
- фактические числа речевых и инструментальных примеров за прогон (`| seen ...` в логе + `accounting.json` в output_dir);
- длительность обработанного аудио (часы) по каждому типу (tgt + ref);
- время обучения;
- loss/NaN/градиенты; точки u0/u250/u500 (+сохранения).

Примечание: `--num_train_epochs` оставлен дефолтным (200), горизонт LR-распада шире 500
шагов → после warmup LR практически постоянен; для A и B одинаково. Числа в логе
`update N/total_updates` относятся к гипотетическому полному прогону — ориентир по бюджету u500.

## Оценка — три области РАЗДЕЛЬНО
1. **Русская речь**: WER/CER, вставки, окончания, ударения, естественность.
2. **Клонирование**: соответствие голосу рефа И отсутствие переноса его слов.
3. **Инструменты**: выполнение операции + сохранение содержания; проверять весь каталог
   AuK, включая функции, которых нет в tools-v3 (эмоции, шёпот, тембр, разделение и т.д.).

Первичная оценка — **без best-of-N и без внутреннего трима**. Автосудья — доп. сигнал;
фонетика и голос — слепым прослушиванием.

## Правило выбора
B принимается, если сохраняет инструменты лучше A **без существенного ухудшения** русского
и клонирования. Если оба ухудшают обязательные функции относительно u10000 — **оба не проходят**.
Допустимые отклонения фиксируются ДО просмотра результатов (ниже).

### Допуски (предрегистрация)
- Русская речь: ухудшение WER не более +0.02 абс. и без новых клиппингов.
- Клонирование: идентичность пары (embed sim) не ниже, чем у u10000, на том же Dev.
- Инструменты: A не обязан сохранять (не обучался); B должен выполнять операцию
  (автосудья ≥7 + слепое прослушивание) и не терять содержание (WER/инсерции в норме).
