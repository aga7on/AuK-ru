# AuK-ru v1.0 — LoRA-адаптеры для русской речи

**Это LoRA-адаптеры (не полные веса).** Русская адаптация модели
[Tencent AuK](https://github.com/Tencent-Hunyuan/AuK) (Flux2Edit + Qwen2.5-Omni-3B +
BigVGANFlowVAE), обученная через цепочку стадий s0→s7.

⚠️ **Модель релизится «как есть» с известными дефектами** — они перечислены ниже честно
и измерены. Это лучшая версия из полученных нами; дальнейшее улучшение требует обучения,
которое упирается в доступное железо.

`7faf25cf…` совпадает).

## Цепочка баз (важно для мержа)

```
ckpts/AuK/auk_base.safetensors          (апстрим Tencent, MIT)
  └─ s0 (транслитерация, r16/α32)
      └─ auk_ru_best.safetensors
          └─ s1 (русская речь, r32/α64)
              └─ auk_ru_10000.safetensors   ← БАЗА для адаптеров в этом репо
                  └─ s7@5750 (эмоции)       ← v1.0
```

Адаптеры v1.0 и s5@4500 мержатся **с одной и той же базой** `auk_ru_10000.safetensors`
(r32/α64). Самой базы в этом репо нет — она получается из апстрим-весов через цепочку s0→s1;
если нужен готовый результат, берите слитые `.safetensors`.

```powershell
python local_train\merge_lora.py --run_dir <run> --ckpt auk_ru_v1.0_s7_5750_lora.pt `
  --out auk_ru_v1.0.safetensors --base_ckpt auk_ru_10000.safetensors --lora_r 32 --lora_alpha 64
```

## Как озвучивать (рецепт v1.0)

```powershell
# TTS: числа/даты/телефоны нормализуются автоматически
python local_train\generate_v1.py --text "Встреча 21.09.2026 в 14:30." --out out_tts

# клонирование голоса + эмоция
python local_train\generate_v1.py --text "Привет, как дела?" --ref ref.wav --emotion happy --out out_clone
```

Скрипты — в [GitHub-репозитории](https://github.com/aga7on/AuK-ru): `generate_v1.py`
(единая точка входа), `ru_frontend.py` (нормализация + ударения), `route_infer.py`
(выбор адаптера по типу запроса), `rerank_composite.py` (best-of-N).

**Рекомендуемая маршрутизация** (измерено на полных гейт-прогонах):

| задача | адаптер | почему |
|---|---|---|
| эмоция (happy/sad/angry/fearful/excited) | s7@5750 | эмо-годен 48.3% vs 36.7% у s5 |
| клонирование голоса | s5@4500 | judge clone 8.20 / phonetics 8.06 |
| обычная TTS без референса | s7@5750 | WER 0.077, first_ok 0.812 |

## ⚠️ Известные дефекты (честно)

**1. Нестабильная артикуляция на трудном русском.** На лёгких текстах произношение
хорошее (accent 9.8/10 по судье), на трудных (числа, даты, длинные составные слова)
проседает до ~7.9–9.0 и появляются фонемные подмены:
- «ключи» → «клучи», «встреча» → «стрича» (палатализация);
- «свои» → «сои», «мы» → «ми» (ы→и);
- «вторая» → «фарая», «января» → «ынгаря» (оглушение/редукция);
- «университета» → «ниверситета» (пропуск гласного).

Человеческое прослушивание 40 пар: **в 45% пар оба варианта с браком** — это главный
нерешённый дефект. Топ проблемных слов: сегодня, университета, тебя, холодильник,
кажется, сколько, работает, целый.

**2. Первый seed нестабилен.** sim первого сида 0.738 против 0.771 у лучшего из трёх
(gap +0.033). Рекомендуется best-of-3 (реализовано в `generate_v1.py`).

**3. naturalness / prosody низкие на трудных текстах** (5.2–5.4 из 10 по судье):
запинки, неестественная интонация на стыке фраз.

**4. Whisper не работает**: инструкция «шёпотом» даёт обычную речь (ΔRMS −0.5 дБ вместо
нужных −2). Ранее давала крик — исправлено до «игнорирует», но настоящего шёпота нет.

**5. Интенсивность эмоций не управляется** (subdued/intense) — экспериментально получено
в s12/s16c, в релиз не вошло.

**6. Code-switching (RU/EN) плохой**: WER 0.55 на фразах типа «задеплой сервис на production».

**7. Аббревиатуры**: «ООО» не читается побуквенно ни в одной форме записи; «МГУ» работает
только в форме «м.г.у.».

**8. Клонирование требует best-of-N**: с одного сида sim ~0.73, медиана по 100 случайным
референсам 0.703 (потолок метрики на коротких рефах — у апстрима без адаптации 0.462).

**9. Адаптеры нельзя складывать**: композиция s7+s5 даёт интерференцию (гейт 0/5,
TTS WER 0.114). Используйте маршрутизацию — выбор одного адаптера под задачу.

**10. Дальнейшее дообучение от v1.0 деградирует**: 5 независимых экспериментов
(S8, S8b, S10-RFT, S16b, S16c, 750–2000 шагов, lr 2e-6…5e-6) показали дрейф TTS/эмоций.
v1.0 = s7@5750 — локальный оптимум цепочки; продолжать обучение «в том же духе»
бессмысленно без смены подхода или данных.

## Методология оценки (для воспроизводимости)

- ASR-метрики: GigaAM (локальный); **CER предпочтительнее WER на длинных словах**
  (WER завышается сегментацией ASR: «частнопредпринимательская» WER 1.0 при CER 0.01).
- Автосудья: Gemini через локальный прокси, схема v3 (tts/clone/phonetics/tool/capability).
  **Согласованность с человеком всего 21%** — судья пригоден для triage, не для финального вердикта.
- Эмоциональный классификатор Aniemore: на RESD 99.3%, но на синтетике — disgust-collapse
  → **невалиден для наших генераций**, не используется.
- Замороженный измерительный набор: `hard_eval_v1` (235 текстов, sha256 в GitHub) —
  никогда не попадает в train.
- Статистика: гейты на n=33…60, поэтому различия <10 п.п. для долей и <0.2 для осей
  судьи статистически не значимы (парные тесты — `GATE_STATISTICS.md` в GitHub).

Полные отчёты по всем стадиям (s0…s16c, включая провальные ветки):
[github.com/aga7on/AuK-ru](https://github.com/aga7on/AuK-ru) → `local_train/reports/deepseek_supervised/`.
