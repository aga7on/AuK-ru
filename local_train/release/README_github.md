# AuK — русская LoRA-адаптация (Ru)

Форк [Tencent-Hunyuan/AuK](https://github.com/Tencent-Hunyuan/AuK) (MIT) —
инструктивная TTS/аудио-модель (Flux2Edit + Qwen2.5-Omni-3B + BigVGANFlowVAE) —
с русской адаптацией через цепочку LoRA-обучения.

> **⚠️ Исследовательский проект.** Вся работа выполнена **в исследовательских и
> образовательных целях**: изучение адаптации TTS к русскому языку, построение конвейера
> данных, LoRA-обучение, разработка метрик и методологии оценки. Публикуется «как есть»
> с полным перечнем известных дефектов — не как продукт.
>
> Это **форк с локальными изменениями**. Веса и датасеты **не входят** в этот репозиторий;
> обученные модели опубликованы на Hugging Face:
> [aga7on/AuK-ru](https://huggingface.co/aga7on/AuK-ru). Аудио-референсы и датасеты
> остаются приватными.
>
> Оригинальный README апстрима: https://github.com/Tencent-Hunyuan/AuK

## Честная оценка результата

| | |
|---|---|
| **Работает** | русская речь по тексту, клонирование голоса, числа/даты/телефоны/единицы, DSP-инструменты (громкость/скорость/питч) |
| **Работает частично** | артикуляция: на простом тексте хорошая, на трудном — нестабильна |
| **НЕ работает** | **эмоции**, шёпот, интенсивность эмоций, code-switching RU/EN |
| **Невозможно далее** | continued fine-tuning от v1.0 — 5 экспериментов дали деградацию |

### ⚠️ Про эмоции — заявление отозвано

Ранее документация утверждала «эмоции работают: 48.3% годен по автосудье» и
«эмоции подтверждены автосудьёй и прослушиванием». **Это не подтверждается независимой
метрикой и отозвано.**

Проверка акустической различимости эмоций (`EMOTION_SEPARABILITY.md`; 60 файлов,
5 эмоций × 2 голоса × 6; **без участия автосудьи**):

| тест | результат | интерпретация |
|---|---|---|
| η² (доля межгрупповой дисперсии) | < 0.10 у **6 из 7** метрик | связь с эмоцией слабая |
| LOO-классификация эмоции | **0.017** при случайном 0.2 | не лучше случайного |
| перестановочный тест (200 шафлов) | **p = 1.0** | сигнала нет |
| Cohen's d, happy vs sad | ≈ 0 по всем метрикам | контраста нет |

Единственная метрика со слабым сигналом — f0 median (η² 0.111, внутри голоса 0.184).
Фактически модель меняет громкость (Δ до 3.4 дБ), а не эмоциональную подачу.

Причина прежней ошибки: согласованность автосудьи с человеческим прослушиванием — **21%**,
поэтому «48.3% годен» оказалось артефактом судьи. Эмоциональный классификатор Aniemore
тоже невалиден на наших генерациях (disgust-коллапс при 99.3% на эталонном RESD).

**Практический вывод:** инструкции вида «say with a happy tone» модель принимает, но
слышимой эмоции не даёт. Флаг `--emotion` в CLI синтаксически существует, эффекта не имеет.

Две метрики зачёркнуты намеренно:

1. **«китайский акцент 0/N»** подсчитывал наличие слова «китайский» в вердиктах судьи.
   Судья **ни разу** не использовал эту формулировку за все прогоны → индикатор был
   структурно зелёным и ничего не доказывал. Заменён на измеряемые оси:
   accent / palatalization / stress / text_fidelity + human mumble rate.
2. **«эмо-протокол годен»** основан на автосудье с 21% согласованности; независимая
   акустическая проверка сигнала не нашла (см. выше).

**Ограничение выборки:** гейты измерены на n=33…60. Парные тесты
(`GATE_STATISTICS.md`) показывают: различия < ~10 п.п. для долей и < ~0.2 для осей судьи
**статистически не значимы**. Цифры выше — порядок величины, не гарантии.

## Что внутри

- `src/` — код модели + инференс (изменения и дополнения к апстриму):
  - `infer_auk.py` — инференс: авто-обрезка длинных референсов (`max_ref_seconds=30`),
    нормализация громкости (`normalize_rms`, RMS −20 dBFS);
  - `ru_frontend.py` — русский frontend (нормализация + ударения);
  - `quality.py` — объективные замеры (WER через GigaAM-ASR, DSP-метрики);
  - `ru_translit.py` — транслитерация (этап s0);
  - `gigaam_ctc.py` — локальный ASR-контроль (GigaAM, только для оценки).
- `local_train/` — конфиги, скрипты слияния/обучения/оценки, отчёты раундов
  (без чекпойнтов, датасетов и секретов).
- `LICENSE` — оригинальная лицензия Tencent (MIT), сохранена как требуется.

## Russian frontend (S9)

Письменный русский → произносимый текст перед моделью:

```python
from auk.infer.ru_frontend import to_speakable
to_speakable("Встреча 21.09.2026 в 14:30, тел. 8-800-555-35-35")
# -> "Встреча дв+адцать п+ервое сентябр+я ... телеф+он в+осемь восемьс+от ..."
```

Конвейер: rutextnorm (числа/даты/валюты/единицы) → tech-prespell
(URL/email/версии/аббревиатуры) → safe_accentize (ударения RUAccent с защитой от
фонетического респеллинга) → опц. транслит.

Regression-бенчмарк: `local_train/hard_cases/hard_cases_ru.jsonl` (241 текст, 10 категорий);
замороженный измерительный набор: `local_train/hard_eval_v1/` (235 чистых позиций, sha256
в `FROZEN.md`, в обучение не попадает). Прогон — `local_train/frontend_probe.py`.
Результаты: S9_FRONTEND.md (wer_mean 0.319→0.255; CER 0.070 — валиднее WER для длинных слов).

## Быстрый старт (v1.0)

Единая точка входа с полным рецептом (frontend → best-of-3 → composite rerank → нормализация):

```powershell
# TTS (нормализация чисел/дат/телефонов встроенная)
python local_train\generate_v1.py --text "Встреча 21.09.2026 в 14:30." --out out_tts

# клонирование голоса
python local_train\generate_v1.py --text "Привет, как дела?" --ref ref.wav --out out_clone
```

Режимы: TTS (без `--ref`), clone (`--ref`). Флаг `--emotion` существует, но **эффекта не даёт**
(см. раздел про эмоции). Best-of-N seeds (7, 123, 999) с composite-скорингом; лучший
копируется в `1_best.wav`. Веса: HF `aga7on/AuK-ru` → `auk_s7_5750.safetensors` + `config.yaml`.

Маршрутизация адаптеров (`route_infer.py`): clone с референсом → s5@4500;
обычная TTS → s7@5750.

## Линейка обучения (доказательная цепочка)

Каждый этап мержится ТОЛЬКО со своей базой (см. `LINEAGE` в отчётах):

| этап | адаптер → база | r/α | описание |
|---|---|---|---|
| s0 | — → `auk_base.safetensors` | 16/32 | транслитерация |
| s1 | `run_ru_s1/model_*.pt` → база s0 | 32/64 | русская речь |
| s2 (A/B) | `run_s2_*/model_*.pt` → база s1 | 32/64 | пилот, выбор ветки |
| s3 | → база s2-B | 32/64 | чистовая речь/клонирование |
| s4 | → база s3 | 32/64 | инструктивный набор |
| s5 @4500 | → база s4 | 32/64 | safety-точка, clone-ветка |
| s7 @5750 | → база s1-10000 | 32/64 | v1.0 (микс v7, emo-доля 0.27) |

Пример слияния:

```powershell
.venv\Scripts\python.exe local_train\merge_lora.py --run_dir local_train\run_s7 `
  --ckpt local_train\run_s7\model_5750.pt `
  --out local_train\run_s7\merged\auk_s7_5750.safetensors `
  --base_ckpt local_train\run_ru_s1\merged\auk_ru_10000.safetensors --lora_r 32 --lora_alpha 64
```

## Обучение

```powershell
& .venv\Scripts\accelerate.exe launch --num_processes 1 --num_machines 1 --mixed_precision bf16 `
  -m auk.train.train --train_jsonl <train.jsonl> --val_jsonl <val.jsonl> `
  --config <base>\merged\config.yaml --init_ckpt <base>.safetensors `
  --output_dir <run> --learning_rate 2e-6 --max_updates 6500 --warmup_steps 25 `
  --frames_threshold 384 --max_samples 2 --save_per_updates 250 --logging_steps 10 `
  --val_per_updates 250 --val_max_rows 100 --seed 18 --lora True --lora_r 32 --lora_alpha 64 `
  --lora_dropout 0.05 --use_ema False --bf16_transformer True
```

Замечания, полученные опытным путём (детали в `ERRORS.MD`):

- **`--mixed_precision bf16` обязателен**, иначе RuntimeError (Float vs BFloat16);
- **`--val_max_rows 100–150` для коротких прогонов**: полная валидация (619 строк × 10 точек
  t-grid = 6190 forward'ов) стоила 14.6 мин на окно — **84% wall-clock** при разбросе
  val loss 0.19%. С патчем прогон 750 шагов: 52 мин → ~15 мин;
- **checkpoint selection не по val loss** (слабый индикатор), а по downstream-гейтам:
  CER hard → mumble rate → phonetic judge → TTS non-regression;
- resume: скопировать последний хороший `model_N.pt` в `model_last.pt` и перезапустить
  ту же команду (train.py сам рескейлит lr оптимизатора к CLI-значению).

## Оценка качества

- ASR-контроль — GigaAM v3 (локально, только для оценки; **CER предпочтительнее WER**
  на длинных словах).
- Автосудья — локальный Gemini-прокси (ключ через env `AUK_GEMINI_KEY`, не коммитится).
  **Пригоден только для triage**: согласованность с человеком 21%, финальный вердикт —
  человеческое прослушивание.
- Три независимые оси произношения: CER + фонемные подмены/артикуляция + human mumble rate.
- Эмоциональный гейт Aniemore — **не используется** (невалиден на синтетике: 99.3% на RESD,
  disgust-коллапс на наших генерациях).
- Статистика: парные тесты обязательны (`paired_gate_test.py`, `GATE_STATISTICS.md`).
- Результаты раундов: `local_train/reports/deepseek_supervised/`.
