## Вердикт и решение (20.09)

1. **Канон остаётся AuK-ru v1.0 = s7@5750.** s10rft@6500 — сильный кандидат (лучшие TTS WER
   0.066 / first_ok 0.833 / tool 8.34 / clone100 objective, эмоции сохранены), но:
   first-shot не улучшен (0.7362 ≈ 0.7378), phonetics judge −0.13, DSP-метрики впритык,
   clone bo3 −0.014. По совокупности — НЕ заменяет v1.0; публикуется как эксперимент
   (sha256 5b1aef1d… зарегистрирован).
2. **Вывод по методу RFT:** 750 шагов на 444 chosen-строках дали заметный сдвиг TTS/tool
   (chosen-пары в основном из TTS/clone-домена), но first-shot не сдвинули — гипотеза:
   BoN-RFT на ~110 уникальных промптах слишком мал; нужен DPO-объектив или ≥1000 пар.
3. **Ветка дообучения приостановлена** (по S8B_RESULTS: три подряд подхода — hard-replay ×2,
   RFT — не дали целевых сдвигов без побочных). Следующие шаги по ROADMAP:
   - S13: human A/B на pairwise_v1 (40 пар готовы) + калибровка весов composite reranker;
   - S11: довести reranker до продуктового (инференс-решение first-shot проблемы БЕЗ обучения:
     composite-выбор из 3 семян уже даёт 0.77+ — это и есть текущий ответ на first-shot);
   - S10-v2 (опционально): расширенный майнинг ≥300 пар + DPO — только после S13-калибровки.
