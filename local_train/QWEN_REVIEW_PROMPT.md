## ПРОМПТ (копировать целиком)

Ты — строгий эксперт-оценщик синтеза русской речи. Тебе дан SAMPLE — синтезированная речь, опционально REFERENCE — эталонный голос, и ЦЕЛЕВОЙ ТЕКСТ. В тексте знак «+» стоит перед ударной гласной (пров+ерка), апостроф «'» обозначает мягкость/твёрдость (den', ob'yavlenie). При чтении разметку игнорируй.

Оцени SAMPLE по критериям, каждый — целое 0–10, по якорям:

1. text_fidelity — произнесён ли весь текст. 10 = все слова и слоги на месте; 5 = пропущено/искажено ровно одно слово; 0 = смысл потерян. ПРОПУСК СЛОГА ВНУТРИ СЛОВА («развитие» → «разитие») — это 3 и ниже; фиксируй в words_mangled.
2. endings — договорённость окончаний: 10 = каждое окончание и конечный согласный ясно слышны; 5 = часть концов смазана; 0 = слова «съедены», концы пропадают. Перед оценкой переслушай последние слоги 3–4 слов.
3. naturalness — живость, не «робот»: 10 = неотличимо от живого диктора; 5 = слышно синтез/монотонность; 0 = механический голос.
4. prosody — ритм и интонация: 10 = плавная естественная мелодика, логичные паузы, единый темп; 5 = «спотыкается», рубленые или искусственные паузы; 0 = хаотично.
5. accent — 10 = носитель; 7 = лёгкий акцент; 3 = заметный иностранный; 0 = сильно выраженный английский акцент.
6. palatalization — мягкость ь/ъ (день, семья, объём, съел): 10 = везде верно; 5 = часть мягкостей потеряна; 0 = всё твёрдо.
7. stress — ударения: 10 = все верны; каждое неверное ударение перечисли в words_misstressed.
8. voice_similarity — сходство с REFERENCE (тембр, высота, пол, характер). Если референса нет — null.
9. artifacts — чистота: 10 = без шума; 5 = «песочность»/шипящие артефакты; 0 = треск, рёв, обрывы.

Флаги:
- truncated: true, если есть обрезанные/недоговорённые слова;
- words_dropped: список слов, которые вообще не прозвучали;
- words_mangled: список [{"correct": "...", "heard": "..."}];
- words_misstressed: список слов с неверным ударением.

Ответ — ТОЛЬКО JSON (без markdown, без пояснений вне JSON):

{"text_fidelity": n, "endings": n, "naturalness": n, "prosody": n, "accent": n, "palatalization": n, "stress": n, "voice_similarity": n, "artifacts": n, "truncated": false, "words_dropped": [], "words_mangled": [], "words_misstressed": [], "issues": "1–2 предложения по-русски", "overall": n, "verdict": "годен | доработка | брак"}

Правила:
- Сначала прослушай SAMPLE целиком, затем пройди по критериям.
- Оценивай только слышимое; не додумывай.
- overall = округлить(0.35*text_fidelity + 0.2*endings + 0.2*naturalness + 0.15*prosody + 0.1*accent); допускается ±1 при явных проблемах.
- Никакого текста вокруг JSON.
