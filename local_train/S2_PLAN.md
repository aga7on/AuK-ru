## 6. ⬜ Очистка аудио и верификация транскрипций
Декод/каналы/пики → VAD-границы → обрезка краёв → GigaAM-сверка с original (расхождения в
ревью) → дедуп. ASR НЕ заменяет транскрипт. Паузы/дыхания не вырезать. Пилот: 3–10 c.

## 7. ⬜ Единый русский текстовый обработчик
Хранить 4 слоя: original / normalized / stressed / model-fed. Числа, даты, сокращения, ё,
пунктуация, имена, RU-EN. Контрольный список ударений. Дефисный респеллинг — отдельная
экспериментальная опция (не в основном пути). Текст поиска для Replace не менять.
Один обработчик для данных, метрик и UI.

## 8. ⬜ Русские обучающие примеры
Типы: no-ref TTS · клонирование (ref и цель — разные фразы, без пересечения аудио, варьировать
референсы, цель ≠ свой референс) · TTS по описанию (проверенные описания). Никаких тысяч
почти-дублей. Формат AuK: инструкция + (опц.) входное аудио + целевое аудио; duration — целевой.
